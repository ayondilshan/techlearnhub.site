# TechLearn Hub 🎓

**Learn. Grow. Succeed.**

TechLearn Hub is a free, AI-powered study platform built for Sri Lankan A/L Technology students. It brings notes, past papers, tutorials and smart study tools together in one place, so students can spend their time studying instead of searching.

🌐 **Live site:** https://techlearnhub.site

## Subjects Covered
- Science for Technology (SFT)
- Information & Communication Technology (ICT)
- Engineering Technology (ET)
- Bio Systems Technology (BST)
- General Information Technology (GIT)
- English

## Features
- 📁 **Resources:** Notes, tutorials and past papers (2019-2026)
- 🤖 **Cypher Study Helper:** Ask study questions and get instant AI answers
- 🧠 **Mind-map Generator:** Turn any topic into a visual mind-map
- 📝 **Quiz Generator:** AI-generated practice quizzes with instant marking
- 💻 **Code Lab:** A place to practise and experiment with code
- 📄 **Past Paper Quizzes:** Practise with past paper questions
